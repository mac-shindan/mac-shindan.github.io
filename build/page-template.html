Mac診断

Mac が重い・固まる原因を、その場で調べます。所要 10 秒。専門知識も管理者パスワードも要りません。

Mac診断.zip をダウンロード

__ZIP_SIZE__ ・ macOS 13 以降 ・ Apple Silicon / Intel 両対応

ボタンが反応しない場合は、次のアドレスをコピーしてブラウザのアドレス欄に貼り付けてください。
__DOWNLOAD_URL__

ダウンロードしたファイルは、あなたの Mac の中で動きます。このページ上では動きません。ブラウザには他人の Mac を調べる権限がないためです。

使い方（この手順は初回だけです）

最後に「Dock に追加しますか」と聞かれます。追加すると、次回からは Dock のアイコンを1回クリックするだけで診断できます。ダウンロードも警告も二度と出ません。

  1. ダウンロードして展開する
    zip をダブルクリックすると Mac診断.app が出てきます。
  2. 右クリックして「開く」を選ぶ
    確認ダイアログが出たら、もう一度「開く」を押します。
    ダブルクリックでは開きません。「開発元を検証できないため開けません」と表示されます。社内で作ったアプリすべてに出る macOS の仕様で、故障ではありません。初回だけ右クリックしてください。2 回目からはダブルクリックで起動します。
    右クリックしても開けない場合（macOS 15 Sequoia 以降）。一度そのままダブルクリックして警告を閉じたあと、システム設定 → プライバシーとセキュリティ を開いてください。下の方に「"Mac診断" は開発元を確認できないため、使用がブロックされました」と出ているので、このまま開く を押します。
  3. 結果を読む
    10 秒ほどでブラウザに結果が開きます。要対応の項目には「対処するとどう変わるか」の目安も出ます。結果はデスクトップにも保存されます。
  4. 「追加する」を選ぶ
    結果が出たあとに確認が出ます。Dock にアイコンが入り、以降はここまでの手順が不要になります。管理者パスワードは要りません。

ページのボタンで診断が始まらない理由

ブラウザには、見ている人の Mac のメモリや CPU を読む権限がありません。もし読めてしまうと、どんなサイトでも他人のパソコンを覗けることになるためです。そのため診断は、一度あなたの Mac に取り込んでから動かす必要があります。

この取り込みを最小にするため、手順は初回の1回だけにしてあります。

調べる項目

項目わかること
スワップメモリが足りず SSD に退避している量。固まる直接原因になります
メモリ空き率空きメモリの割合
圧縮メモリ限界まで圧縮されているメモリの量
モニタ接続方式外部モニタが直結か、CPU で映像を作る方式か。ここが原因なら買い替えずケーブル交換で解決します
画面描画の負荷画面を描くのに使われている CPU
熱による性能低下熱で CPU の速度が絞られていないか
起動中のプロセス数Chrome・node・Claude がいくつ動いているか
最後の再起動から経過日数

見るもの・見ないもの

取得します

  • メモリやディスクの使用量
  • 機種名・チップ・搭載メモリ
  • モニタの接続方式
  • プロセスの個数

取得しません

  • ファイル名・書類の中身
  • ブラウザの履歴・開いているタブ
  • アカウント情報・パスワード
  • どのアプリで何をしていたか

結果はあなたの Mac の中にだけ保存され、自動で送信されることはありません。情シスに相談するときは、結果画面の「結果をコピー」ボタンを押して貼り付けてください。何を送るかはあなたが決められます。

うまくいかないとき

「壊れているため開けません。ゴミ箱に入れる必要があります」と出る場合、古い版が残っています。ゴミ箱に入れて、このページからもう一度ダウンロードし直してください。2026-08-17 より前に配った版で起きます。

管理者パスワードを求められた場合、それはこのツールではありません。閉じて情シスに連絡してください。

「熱による性能低下」が「取得できませんでした」と出ることがあります。Apple Silicon の Mac では数値を読めないためで、正常という意味ではありません。
