# Mac ドクター

Mac が重い・固まる原因を調べて、日本語で対処法を表示する診断ツールです。
PC に詳しくない人が自分で実行できることを目的にしています。

ターミナルは使いません。アイコンをダブルクリックすると 10 秒ほどで
ブラウザに結果が開きます。管理者パスワードも要りません。

## ダウンロード

**配布ページ: https://miyauchi0622.github.io/mac-doctor/**

使い方の説明つきのページです。ログインは不要です。

ファイルだけ欲しい場合は
[こちらから直接ダウンロード](../../releases/latest/download/Mac-Shindan.zip)できます。

macOS 13 以降 / Apple Silicon・Intel 両対応

## 使い方

1. zip を展開して `Mac診断.app` を取り出す
2. **右クリック →「開く」** を選ぶ（初回のみ。ダブルクリックでは
   「開発元を検証できないため開けません」と表示されます）
3. 10 秒ほどで結果がブラウザに開く
4. 最後に出る「Dock に追加しますか」で追加すると、次回からは
   Dock のアイコン 1 クリックで診断できます

結果はデスクトップに `Mac診断結果_日付.html` として保存されます。

## 調べる項目

| 項目 | わかること |
|---|---|
| スワップ | メモリ不足で SSD に退避している量 |
| メモリ空き率 | 空きメモリの割合 |
| 圧縮メモリ | 限界まで圧縮されているメモリの量 |
| モニタ接続方式 | 外部モニタが直結か DisplayLink 経由か |
| 画面描画の負荷 | WindowServer の CPU 使用率 |
| 熱による性能低下 | 熱で CPU の速度が絞られていないか |
| 起動中のプロセス数 | Chrome / node / Claude の個数 |
| 最後の再起動から | 経過日数 |

要対応の項目には「対処するとどう変わるか」の目安も表示されます。
スワップ・圧縮メモリの解放と熱の回復は仕組み上必ず起きるため断定して
表示し、それ以外は根拠を添えた概算として表示します。

「熱による性能低下」は Apple Silicon の Mac では数値を取得できないことが
あります。その場合は「取得できませんでした」と表示します。正常という意味では
ありません。

## プライバシー

**取得するもの**: メモリやディスクの使用量、機種名・チップ・搭載メモリ、
モニタの接続方式、プロセスの**個数**

**取得しないもの**: ファイル名、書類の中身、ブラウザの履歴、開いている
タブ、アカウント情報、プロセスのコマンドライン全文

結果は実行した Mac の中にのみ保存されます。**自動送信は一切行いません。**
共有するかどうかは、結果画面の「結果をコピー」ボタンを押すかどうかで
利用者が決められます。

`sudo` は使いません。管理者パスワードを求められた場合、それはこのツールでは
ありません。

## 仕組み

計測と判定を分離しているのが設計の要点です。判定は数値を入力すれば答えが
出るだけの部品なので、実機がなくてもテストできます。

| ファイル | 責務 |
|---|---|
| `src/thresholds.sh` | 閾値の定義のみ |
| `src/collect.sh` | 計測。実機依存 |
| `src/judge.sh` | 判定。実機非依存なのでテストできる |
| `src/report.sh` | 結果画面の生成 |
| `src/install.sh` | 2 回目以降をワンクリックにする設置 |
| `src/mac-doctor.sh` | 実行本体 |

macOS 標準の bash と標準コマンドだけで動きます。Python も Homebrew も
必要ありません。配布先に開発環境があるとは限らないためです。

## 開発

```bash
bash tests/test_judge.sh     # 判定ロジックのテスト（実機不要）
bash tests/test_report.sh    # 結果画面のテスト
bash tests/test_install.sh   # 設置処理のテスト
bash tests/smoke_collect.sh  # 実機計測のスモークテスト

bash build/build-app.sh      # 配布用アプリの生成
bash build/build-page.sh     # 配布ページの生成
```

判定基準を変えるときは `src/thresholds.sh` だけを編集します。
